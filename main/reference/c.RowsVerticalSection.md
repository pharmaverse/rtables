# Combine `RowsVerticalSection` objects

Combine two or more `RowsVerticalSection` objects (as returned by
[`in_rows()`](https://pharmaverse.github.io/rtables/reference/in_rows.md))
into a single object

## Usage

``` r
# S3 method for class 'RowsVerticalSection'
c(...)
```

## Arguments

- ...:

  `RowsVerticalSection` objects

## Value

A single `RowsVerticalSection` object containing all row sections from
the objects passed to `...`
